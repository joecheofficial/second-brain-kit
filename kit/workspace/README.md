# My second brain

Private. This folder lives only on this computer. Do not put it in a public
place, do not push it to GitHub, and do not share it.

- Find something: `node kit/brain.mjs find "words you remember"`
- See everything as a map: `node kit/brain.mjs map`
- Bring in new exports: drop the zip in `inbox/`, then `node kit/brain.mjs refresh`
- Check it is healthy: `node kit/brain.mjs doctor`

Your assistant knows how to use this folder: see `AGENTS.md`.
